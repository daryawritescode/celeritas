# Celeritas ⚡

Welcome to the Celeritas documentation!

Celeritas is a high-performance network utility designed for modern environments. It provide speedtest capabilities, latency monitoring, and a real-time dashboard.

## 🚀 Quick Links

- [Getting Started](setup.md): Install and run your first speedtest.
- [Usage Guide](usage.md): Explore the CLI and Web Dashboard.
- [Configuration](config.md): Customize Celeritas for your environment.
- [API Reference](api.md): Technical details for developers.

## ✨ Core Features

- Native Speedtests via CLI and Web.
- Gateway and DNS Latency tracking.
- Interactive Dashboard with Chart.js.
- Local SQLite persistence with Polars integration.
